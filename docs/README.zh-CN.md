## 1. 介绍

用于在 Release 环境下查看日志的系统。这个系统的诞生源于实际开发过程中遇到的几个具体问题：

1. 测试工程师在测试过程中发现问题时，往往难以准确判断问题的来源；
2. 由于责任归属不明确，许多问题都被默认记录给了前端开发人员；
3. 一些偶发性问题出现一次后可能短期内无法复现，这给问题定位带来了很大困扰；
4. 对于网络日志每次使用 charles 过于繁琐。

通过这个日志系统，我们可以直接查看日志来定位问题，无需测试人员反复尝试复现。为了让系统发挥最大效用，我们建议在日常开发中尽可能详细地记录日志信息，这样可以更好地帮助我们排查和解决各类问题。

<span style="color: red; font-style:italic">*特别提醒：尽量不要在线上使用，除非你进行了特别完善的测试。</span>

## 2. 集成

在使用日志系统之前，你首先需要集成 [log-listener-plugin](https://github.com/wutiange/log-listener-plugin) 到你的项目。具体集成教程请参阅对应的文档。

[log-listener-plugin](https://github.com/wutiange/log-listener-plugin) 只支持 [react-native](https://www.reactnative.dev/) 项目。

## 4. 本 fork 的增强

上游功能保持原样，以下是实际每天用它调式时补上的功能。

### 4.1 网络接口列表

| 功能 | 说明 |
| --- | --- |
| **标记接口** | 在接口上右键选「标记」。标记过的接口在清除列表时**不会被清掉**，方便在噪声里盯住关心的几条；快速双击清除按钮则连标记一起清空。 |
| **耗时** | 每条显示「请求发出 → 收到响应」花了多久，例如 `123ms` / `2.50s`；还在等响应的留空。 |
| **列布局** | 序号 / 状态码 / 耗时 / 请求方法 装在一个框里，格子之间用竖线分隔；接口地址在框外，占满剩余宽度。 |
| **关键词高亮** | 按关键词规则给整行上色，每条规则带启用勾选框，可以临时关掉而不删配置。 |
| **忽略规则** | 把吵闹的接口整条隐藏（底部会提示隐藏了多少条）。 |
| **路径显示** | 隐藏开头的路径段让长 URL 更好读。隐藏的路径段不参与任何匹配，配置以「相对域名」形式保存，换域名仍然生效。 |
| **树 / 平铺视图** | 一键在「按路径分组的树」和「按到达顺序平铺的列表」之间切换。 |

### 4.2 接口详情

| 功能 | 说明 |
| --- | --- |
| **请求体 / 响应体查看器** | 支持搜索高亮、只看匹配、展开/折叠全部、整段复制、双击节点复制该节点的值。请求体、响应体、重新请求结果三处共用同一个组件。 |
| **重新请求** | 可以改请求头（只改值，字段名保持原样）和请求体，然后从电脑端重新发出去并就地看结果。请求由 Electron 主进程发出，不受 CORS 限制；结果块的布局和响应块一致。 |
| **一键复制** | 请求参数、请求体、响应体都能一键复制。 |

### 4.3 连接

| 功能 | 说明 |
| --- | --- |
| **标题栏显示本机 IP** | 显示在标题旁边，点击即复制。 |
| **全部 IP** | 「设置 → 连接说明」里会列出**所有**候选地址（推荐的在第一个），第一个连不上可以换一个试；同时列出**被排除**的地址（虚拟网卡 / VPN）。这样就不会显示 `10.8.0.x` 这种手机根本连不上的 VPN 地址。 |
| **排查提示** | 代理 / VPN 软件、Windows 防火墙弹窗的提醒。 |

### 4.4 窗口

窗口大小、位置和分栏宽度都会记住，下次打开保持一致。

### 4.5 设备（adb）

内置了一个 adb 面板，插上数据线就能在应用里直接操作手机，不用再开命令行。

| 功能 | 说明 |
| --- | --- |
| **adb 自动探测** | adb 不是系统自带程序，位置因人而异。会按「手动指定 → 应用内置 → ANDROID_HOME → 各系统 SDK 默认路径 → PATH」逐个找，找到后只用完整路径调用。全都没命中时界面上给「选择 adb 文件」按钮，选完记住；手动指定的路径坏了会直接报错，不会偷偷用别的 |
| **设备列表** | 型号 / 品牌 / Android 版本 / 连接方式 / 状态一目了然，多设备可切换。未授权时直接提示去手机上点「允许 USB 调试」 |
| **拖 APK 安装** | 把 .apk 拖到「安装应用」磁贴上就装好了。带进度百分比（先 push 到手机再 pm install）、已用时间、取消按钮，传输卡住 2 分钟会自动中止。可勾选「安装后自动打开」，装完直接把 App 拉到前台 |
| **卸载应用** | 列出已装应用（默认只列第三方，可勾选包含系统应用），支持搜索。卸载前二次确认，可选保留数据（-k） |
| **截图** | 截手机当前画面并预览，可保存到电脑。息屏时会明确提示（否则截出来是全黑的），并提供一键唤醒 |
| **屏幕常亮** | 插着电时不让屏幕熄灭（调试时不用一直戳屏幕）。开关打开时会顺便点亮屏幕，没插电时也会说明「暂时不生效」 |
| **无线调试** | 插线时点一次「开启」，之后拔线也能连；填手机 IP 即可连接 |
| **投屏操控** | 右侧面板显示手机实时画面，可以直接用鼠标点（轻触）、按住拖动（滑动）、滚轮（滚动），方向键/回车等键也能发过去。息屏时会说明并给「唤醒屏幕」按钮 |
| **自定义命令** | 直接跑 adb shell 命令，输出进下方的面板 |

所有命令的原始输出都会汇总在页面下方的输出面板里，成功绿色、失败红色。
